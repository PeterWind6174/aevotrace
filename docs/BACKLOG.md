## 已识别的局部加固项

- Python wrapper 对真实 C stale token（slot 复用后的旧 token）的端到端 observer 测试；当前已有零 handle、wrong-thread、reentry、构造失败等覆盖。
- registry 的 `module!symbol` 别名政策：目前实现按 id/args/ABI 匹配；是否禁止别名需要先改契约，不能暗自扩展承诺。
- 超长导出名上限与查询截断的一致性；少见 C ABI 错误优先级、runner table-full/handle-lost 分类口径。
- 磁盘满/Trace 中途写入失败、generation 回绕、并发极端竞争等未覆盖路径。
- bit-for-bit 构建可复现口径与路径/LC_UUID 差异；当前已验证的是哈希绑定的实际产物和行为。
- 早期 Unicorn GUI 的占位 API 和有限消息语义仅属于历史实验，不能进入后续产品支持声明。

这些局部项目不阻断已经独立通过的 session-fix 有界修复验收。`parse_exports` 当前已排序，不能把旧评审的排序猜测当成已复现缺陷。
